# 独立PHITS領域集計ツールの使い方

このツールは、計算済みのPHITS Sumtally合算線量と対応する`_err.out`を読み、
球または検証済みRTSTRUCT領域の線量統計を表示します。PHITS、Sumtally、
DICOM変換は実行しません。研究・教育用の独立ツールで、dicomxphits本体GUIの
完了判定や臨床上の判断には使いません。

英語の詳細な入力契約は[Independent PHITS ROI statistics](phits-roi-statistics.md)
にあります。

## 起動

リポジトリのルートで、依存ライブラリが入ったPython 3.12を使用します。

```powershell
.venv/Scripts/python.exe tools/phits_roi_stats_gui.py
```

Windowsでは、リポジトリ直下の`run_phits_roi_stats_gui.bat`をダブルクリックしても
起動できます。BATは自身の場所を基準に`.venv`のPythonを使用します。

画面はdicomxphits本体と同じ濃紺・水色系です。小さい画面では右端の
スクロールバーで下の結果・保存欄へ移動できます。結果表の右側の列は
表の下の横スクロールバーで確認してください。

## 表示言語を切り替える

画面上部の **「表示言語 / Language」→「日本語」または「English」** で
表示を切り替えられます。起動時は日本語です。入力したパス、ROI選択、
追加済みケース、集計結果は保持され、言語変更による再集計は行いません。
集計中にも切り替えられ、完了メッセージはその時点の表示言語になります。

ファイル名、DICOMのROI名、結果の値・単位・状態コード、CSV/JSONの項目名、
解析診断の原文は変わりません。OSのファイル選択画面はOSの表示言語に従います。
言語設定は保存せず、次の起動時は日本語に戻ります。

## まず解析元を選ぶ

画面上部の**「ZIPを選択」**または**「フォルダを選択」**で、計算済みケースを指定します。
場所を直接入力した場合は**「入力した場所を読み込む」**を押してください。
解析元は読み取り専用です。

続く7欄は**解析元ZIP／フォルダの中にあるファイルの相対パス**です。
dicomxphitsの標準配置で候補が一意なら「自動候補・変更可」として入力されます。
候補が複数ある欄や見つからない欄は空欄です。各欄は直接編集でき、
**「選択…」**から別のファイルを選び直せます。ZIPでは内部ファイルの検索画面、
フォルダではファイル選択画面が開きます。フォルダの外にあるファイルは、
この7欄には指定できません。

| 画面の欄 | 通常のファイル |
|---|---|
| 合算線量 | `sumtally/deposit-target-3D_sum_all_active_segments_totalfield.out` |
| 対応するr.err | 同じ`sumtally`内の`…_err.out`、または保存された`.sumtally-run-*`内の対応ファイル |
| 保存実行内の同一線量 | r.errを`.sumtally-run-*`から選ぶとき、そのフォルダ内の`…totalfield.out` |
| Sumtally生成サマリー | `analysis/sumtally_generation_summary.json` |
| Sumtally実行サマリー | `analysis/sumtally_execution_summary.json` |
| セグメントマニフェスト | `segments/segment_manifest.json` |
| PHITS準備サマリー | RTSTRUCT集計時のみ、`analysis/public_preparation_workspace_summary.json` |

ZIP内の最上位フォルダ名はケースによって異なるため、表では省略しています。
入力欄にはZIP内の完全な相対パスが表示されます。保存実行が複数ある場合、
GUIはr.errの保存先を決めず、該当欄を空欄にします。候補の名前だけでは
正しい線量の組とは確定しません。**「集計する」時に線量・誤差・証拠を再検証**します。

## 球を集計する

「球」を選びます。初期値は中心`(0, 0, 0) cm`、半径`0.25 cm`、
サンプリング間隔`0.1 cm`（1 mm）です。入力が揃ったら「ケースを追加」、
続いて「集計する」を押します。複数のケースを追加して一覧表示できます。

1 mmサンプリングの81点と0.081 cm³は、球の形を示す参考値です。
幾何体積は約0.06545 cm³です。線量計算に使う`Grid Points`は、
**実際のPHITS格子で球内に中心が入ったセル数**なので81点とは別です。

## RTSTRUCTの領域を集計する

「RTSTRUCT」を選び、画面下部の**「RTSTRUCT DICOM（領域輪郭）」**から
RT Structure Setファイルを選びます。拡張子が`.dcm`でないファイルも選択可能です。
上の**「PHITS準備サマリー」欄はJSONであり、RTSTRUCT本体ではありません。**

さらに、対応する次の入力を個別に指定します。

1. 凍結された計算ワークスペース。
2. その計算で使ったCT2PHITS凍結スナップショット内のCT参照DICOM。
3. 対応するRTPLAN DICOM。
4. RTSTRUCTを選んで「ROIを一覧」を押し、番号と名前を確認してROI番号を選択。

凍結CT2PHITSスナップショットにはCTシリーズ、ワークスペースマニフェスト、
実行サマリー、DATfilesの証拠が必要です。ワークスペースには対応する準備
サマリーとセグメントマニフェストが必要です。RTSTRUCT中に`Chamber`という
名前があるだけでは、PHITS格子のどのセルか確定しません。必要な証拠や
座標が一致しなければStructure値は「invalid」となり、球の値で代用しません。
RTSTRUCT・RTPLAN・CT・ROI番号はファイル名から自動決定しません。

## 数値の意味と保存

線量は検証済みの**1回照射分のGyを100倍したcGy**です。
**「Mean cGy」**は選択セルの平均線量です。**「Cell sum cGy」**は
選択セルの線量値を単純に足した数で、格子セル数に依存します。
領域の物理的な総線量や平均線量を意味しません。`Spatial SD`はセル間の
線量ばらつき、`r.err`は各セルのPHITS相対統計誤差です。

結果のCSVとJSONが必要な場合だけ、リポジトリと入力ケースの外にある
既存フォルダを指定して保存します。同名ファイルは上書きしません。
患者氏名・IDなどのDICOMタグ、UID、入力の絶対パス、線量格子は自動出力
しません。ケース名とRTSTRUCTのROINameは結果の表示名になるため、保存前に
個人情報を含まないか確認してください。

## 入力できないとき

- 欄が空欄：標準配置の候補がないか、複数あります。「選択…」で確認します。
- 「ケースを追加」が無効：必須欄、解析元内のファイル、またはRTSTRUCT時の
  外部DICOM・ROI番号が不足しています。
- 「集計する」が無効：先に「ケースを追加」を押してください。ケースが一覧に
  入ると「集計する」が有効になります。
- RTSTRUCTで結果が無効：まずワークスペース、凍結CT2PHITS証拠、RTPLAN、
  RTSTRUCTが同じ計算を指すか確認します。名前の一致だけでは通りません。

合成データによる[GUI検証記録（英語）](phits-roi-gui-validation.md)もあります。
